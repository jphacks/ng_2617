# フロント統合の実装状況

2026年10月25日。`frontend-merge-plan.md` と `edit-lifecycle-plan.md` の合意事項を、共通モデル・サーバー・HTTP/SSE・クライアント・画面へ接続した。元の計画書は設計の経緯として残し、現在の契約はこの文書と `board-model.md`・`board-server.md`・`board-client.md` を参照する。

## 実装した機能

- WordCard / BlockCard、構造化UUID、寸法、BlockCardだけの関連先・リアクション、独立した矢印。
- 空カードの追加、本文・色・書体、単一・複数移動、四隅からのカード全体のリサイズ。
- 貸し出し単位の編集ロック、期限確認、途中保存、確定／取消要求の回収、無応答解除。
- 即時操作によるリアクション、矢印、一括削除、全消去、サンプル復元。
- 初期5分の共有カウントダウンとサーバー側の終了フック。
- 手動／自動で共通の候補生成・配置、関連性指定、生成状態と生成IDの配信、端末ごとの画面外案内。
- 要求IDの二重実行防止、異内容の拒否とログ、HTTPのタイムアウト時の状態保持・元の要求の再送。
- `Adjust` の配置を基準にした画面と `Adjust_room` のルーム入口。`/room/:roomId` で同じボードを共有する。

## 未確定だった点で今回採用した実装

| 項目 | 今回の選択 |
| --- | --- |
| 種類 | `word` / `block`。編集による種類変更は受け付けない |
| 寸法 | ボード座標のpx。通常210×210、関連310×330。最小160×150 / 260×280、最大各2000 |
| 固定Reaction | `thumbs-up` 👍、`heart` ❤️、`idea` 💡、`thinking` 🤔、`celebrate` 🎉 |
| 保存単位 | `CardChange[]` の属性パッチ。ID・種類・編集者・リアクションは本文保存に含めない |
| 削除済み関連先 | 保存時に除去して受理。自己参照・重複は拒否 |
| 存在しない対象の削除 | 変更なし。ロック取得・保存で存在しない対象を指定すると拒否 |
| 許可待ちの本文入力 | 許可まで読み取り専用。仮移動・仮サイズだけを許可待ちから保持 |
| 仮移動と最新値の合成 | 開始時からの位置・サイズの差分を許可時の最新カードへ適用 |
| 本文編集中の移動 | 先に本文を確定／取消してから移動。異なる貸し出しを同端末で重ねない |
| 空白タップ | キャンバス背景で250ms未満・移動6px以下。パン、長押し、カード・UIの操作は確定しない |
| 生成の更新順序 | `generationSequence` をrevisionと分けて判定。1生成をgenerationId、案内をeventIdで識別 |
| 手動生成後 | 自動と同じ生成更新として記録し、更新なしで続けて自動生成しない |
| 初期取得の境界 | SSEの最初のスナップショットを初期取得に使う。独立したGETの後に購読する方式を廃止 |
| HTTP応答不明 | SSE・最終内容・要求IDを保持。UIの「元の要求を再送」で同じ内容を送信。自動再送はしない |
| SSE切断・再接続 | 編集下書きと案内を破棄して確定状態へ再同期。残ったロックはサーバーが期限確認で回収 |
| 再送結果の保持 | 単一プロセスの生存期間中、メモリに保持。期限や容量制限、永続化は未導入 |
| 時刻補正 | スナップショットのserverNowと受信時刻との差を表示に使用。往復遅延の精密推定はしない |
| 新しいルーム | GET/SSEの初回アクセスで空ボードを作成。`demo` は起動時にサンプルを作成 |

## ファイル構成

- `src/domain/board.ts`：モデル・ID・既定値・純粋操作・サンプル。
- `src/domain/board-protocol.ts`：コマンド、スナップショット、生成状態、属性パッチ。
- `src/domain/board-validation.ts`：HTTP要求とHTTP/SSE受信値の実行時検証。
- `src/server/board-service.ts`：種類別ハンドラー、貸し出し台帳・カード索引、一括更新、再送結果管理。
- `src/server/edit-lifecycle.ts`：期限5分、問い合わせ10秒、自動追加待機30秒、最大3語。
- `src/server/word-addition.ts`：候補の重複除去と既存カードの右への配置。
- `src/server/ai-service.ts`：関連性を受け取るモック候補生成。外部AI APIは呼ばない。
- `src/server/board-timer.ts`：0秒到達時の空の `onTimerFinished` 拡張点。
- `src/client/board-client.ts`：確定状態・下書き・仮表示・送信状態・再送。
- `src/client/http-board-transport.ts`：HTTP操作とSSEによる初期取得・更新。
- `src/client/generated-guidance.ts`：端末の表示範囲とカード全体による案内判定。
- `src/components/Board.tsx` / `BoardCard.tsx`：React Flowと共通クライアントの接続。
- `src/components/CardTextInput.ts`：IME入力をノードの非同期反映から分離し、入力値と変換中のキー操作を保護。

## 運用上の範囲

単一プロセスのメモリ実装。ボード、貸し出し、要求結果、タイマーはプロセス終了で失われ、複数プロセス間では同期しない。常時動作する1つのNext.jsプロセスで実行する。
ブラウザのlocalStorageでユーザーIDを共有し、マウントごとに別のclientIdを発行する。これらは自己申告の識別情報で、認証ではない。操作要求から他人のリアクションユーザーを個別指定することはできないが、本人確認・アクセス制御は未導入。
旧ID・旧カード型を扱う永続データの移行、外部AIの接続、キー割り当て変更設定は実装していない。旧データは推測で変換しない。
