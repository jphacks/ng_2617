# 実装ドキュメント

共同編集型ブレーンストーミングボード「芽生え」の実装・仕様・開発手順への入口です。各文書で分かることと、目的に応じた読む順序をまとめています。

製品概要と使い方は [README](../README.md) を参照してください。

## はじめに読む

1. [セットアップ手順](./get_start.md)で、開発環境の起動、Geminiの設定、検証コマンドを確認します。
2. [実装状況](./implementation.md)で、実装済みの機能、採用した仕様、ファイル構成、運用上の制約を把握します。
3. [共通モデル](./board-model.md) → [サーバー](./board-server.md) → [クライアント](./board-client.md)の順に読むと、共有するデータから操作・同期・画面への反映までを追えます。
