## 製品概要

アイデア出しの時に行き詰まってしまいがちな点を、ユーザーが手を動かす形で解消します。

### 背景・課題

私たちはJPHACKSに向けたアイデア出しに想定以上の時間をかけました。
その様子を振り返った時に、以下の二つのケースで行き詰まってしまっていたことがわかりました。

- ブレーンストーミングのとき、何も思いつかなくなり、手が進まなくなって何もせず終了を待ってしまう
- アイデア同士を組み合わせて新しい案をたくさん出したいのに、既に考えた案についてばかり考えてしまう

また、AIに独創的なアイデアを求めて時間を浪費する場面もありました。

### 製品説明（具体的な製品の説明）

こちらのurlから実際に動かすことができます。複数人での共同作業に対応しているのでぜひ試してみてください。

https://ya-sheng-e.onrender.com/

#### 基本機能

- 他の人と同じルームIDを入力することで、複数人で同じボードを共有して作業することができます。
- 単語を記入する付箋や付箋同士をつなぐ矢印などの基本的なツールのほか、付箋ツール同士を紐づけてアイデアをまとめられる関連カードを実装しています。
- 関連カードに書かれたアイデアにはユーザーごとにリアクションをつけることができます。
- ボードの状態をJSONやSVGの形式で出力でき、保存されたJSONファイルを読み込むことでボードの状態を復元することができます。
- 同じボード上の全員が一定時間付箋の編集をしていなかった場合、手が行き詰まっていると判定して関連性が低い言葉を自動生成します。
- 神経衰弱モードでは、ボード上の言葉をが書かれたカードを順に2枚めくり、それらと関連するアイデアを記入します。他の人が記入している様子を確認することもできます。記入したアイデアは関連カードとしてボード上に追加されます。

### 特長・課題解決

#### 1. 特長1

- ブレーンストーミングで行き詰まって手が止まってしまったことを検知し、AIが関連性の低い新しい言葉を投下します。AIによって追加された言葉から新たに言葉を広げることを促し、ユーザーの新しい発想のきっかけを作ります。

#### 2. 特長2

- 出てきた言葉をカードに見たてて全てひっくり返し、神経衰弱のようなゲームを行い、めくった2枚の言葉からアイデアを創出させます。ブレーンストーミング時に出てきた言葉全体を意識させ、様々なアイデアの創出を促すと同時にユーザーの視野が狭くなることを防ぎます。

#### 3. 特長3

- AIの活用は新しい単語を発生させるのみにとどめ、アイデアを考える部分はユーザーの独創性にゆだねることによって、AIには考えつかないアイデアが期待できます。

### 今後の展望

- アイデア発想のプロセスに、神経衰弱以外のゲームを追加してバリエーションを持たせたい。
- 他のアイデア創出法を組み合わせて、より効果的なアイデア創出を促進したい。
- プロダクトの内容と名前、演出について統一感を持たせたい。
- 単語同士の関連性という観点から、word2vecなどの手法にも挑戦したい。
- ユーザーに関する情報を保存したり、ほかのユーザーのカーソルを可視化できるようにしたい。

### 注力したこと（こだわり等）

- 言葉と言葉の関係性に重点を置いています!当初はチーム名にもある写像を軸とする案を考えていたのですが、写像の定義を満たすものを思いつかなかったので妥協して関係に落ち着きました。
- 単語やアイデアをカードとして共有し、そのつながりを可視化しながら、チームで発想を広げられるボードを開発しました。関連付け・矢印・リアクションにより、アイデアを出すだけでなく、整理して議論するところまで支援します。SVG出力とJSON保存・読み込みにも対応し、活動の成果を共有・再利用できます。
- 特に力を入れたのは、共同編集の使いやすさとデータの整合性の両立です。同時編集の競合防止、通信失敗時の二重実行防止、日本語変換中の入力保護など、実際に複数人で使う場面を想定した細部まで作り込みました。
