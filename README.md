## 製品概要

アイデア出しのときどうしようもなく止まってしまうその手に、AIが運んでくる言葉の種が再び活力を与えます！

### 背景課題

- ブレーンストーミングのとき、何も思いつかなくなり、手が進まなくなって何もせず終了を待ってしまう
- アイデア同士を組み合わせて新しい案をたくさん出したいのに、既に考えた案についてばかり考えてしまう

### 製品説明（具体的な製品の説明）

### 特長

#### 1. 特長1

- ブレーンストーミングで行き詰まって手が止まってしまったことを検知し、AIが関連性の低い新しい単語を投下。

#### 2. 特長2

- 出てきた言葉をカードに見たて全てひっくり返し、神経衰弱のようなゲームを行う。めくった2枚の言葉からアイデアを思いつくことができたら獲得。

#### 3. 特長3

### 解決出来ること

- 特長1
  AIによって追加された言葉から新たに言葉を広げることを促し、ユーザーの新しい発想のきっかけを作る。
- 特長2
  出てきた言葉全体を意識させ、様々なアイデアの創出を促すと同時にユーザーの視野が狭くなることを防ぐ。

### 今後の展望

### 注力したこと（こだわり等）

- 既存のブレーンストーミングツールでは、出てきた単語やアイデアから別のアイデアを作るときにノードやグルーピングツールを用いるものが多いですが、付箋の位置などの制限によって最終的に煩雑な見た目になりがちでした。
  今回作成したものでは、アイデアをまとめるブロック内に元となった付箋の情報を表示する形式にしているため、最終的なボードでも見た目がすっきりします。
