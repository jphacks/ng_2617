# 芽生え

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要

アイデア出しのときどうしようもなく止まってしまいそうなその手に、AIが運んでくる言葉の種が再び活力を与えます！

### 背景・課題

私たちはJPHACKSに向けたアイデア出しに想定以上の時間をかけました。
その様子を振り返った時に、以下の二つのケースで行き詰まってしまっていたことがわかりました。

- ブレーンストーミングのとき、何も思いつかなくなり、手が進まなくなって何もせず終了を待ってしまう
- アイデア同士を組み合わせて新しい案をたくさん出したいのに、既に考えた案についてばかり考えてしまう

また、AIに独創的なアイデアを求めて時間を浪費する場面もありました。

### 製品説明（具体的な製品の説明）

アイデア出しの時に行き詰まってしまいがちな点を、ユーザーが手を動かす形で解消します。
### 特長

#### 1. 特長1

- ブレーンストーミングで行き詰まって手が止まってしまったことを検知し、AIが関連性の低い新しい単語を投下。

#### 2. 特長2

- 出てきた言葉をカードに見たてて全てひっくり返し、神経衰弱のようなゲームを行う。めくった2枚の言葉からアイデアを発想させる。

#### 3. 特長3

- あくまでもAIは新しい単語を発生させるのみである。

### 解決出来ること

- 特長1
  AIによって追加された言葉から新たに言葉を広げることを促し、ユーザーの新しい発想のきっかけを作る。
- 特長2
  出てきた言葉全体を意識させ、様々なアイデアの創出を促すと同時にユーザーの視野が狭くなることを防ぐ。
- 特長3
  アイデアを考える部分はユーザーの独創性にゆだね、AIには考えつかないアイデアが期待できる。

### 今後の展望

- アイデア発想のプロセスに、神経衰弱以外のゲームを追加してバリエーションを持たせたい。
- 他のアイデア創出法を組み合わせて、より効果的なアイデア創出を促進したい。
- llmを連携するところまで至らなかったため、そこまでの実装を進めたい。
- プロダクトの内容と名前、演出について統一感を持たせたい。
- 単語同士の関連性という観点から、word2vecなどの手法にも挑戦したい。

### 注力したこと（こだわり等）

- 言葉と言葉の関係性に重点を置いています!当初はチーム名にもある写像を軸とする案を考えていたのですが、写像の定義を満たすものを思いつかなかったので妥協して関係に落ち着きました。
- 単語やアイデアをカードとして共有し、そのつながりを可視化しながら、チームで発想を広げられるボードを開発しました。関連付け・矢印・リアクションにより、アイデアを出すだけでなく、整理して議論するところまで支援します。SVG出力とJSON保存・読み込みにも対応し、活動の成果を共有・再利用できます。
- 特に力を入れたのは、共同編集の使いやすさとデータの整合性の両立です。同時編集の競合防止、通信失敗時の二重実行防止、日本語変換中の入力保護など、実際に複数人で使う場面を想定した細部まで作り込みました。
