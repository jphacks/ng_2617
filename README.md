## 製品概要

アイデア出しのときどうしようもなく止まってしまうその手に、AIが運んでくる言葉の種が再び活力を与えます！

### 背景・課題

私たちはJPHACKSに向けたアイデア出しに想定以上の時間をかけました。
その様子を振り返った時に、以下の二つのケースで行き詰まってしまっていたことがわかりました。

- ブレーンストーミングのとき、何も思いつかなくなり、手が進まなくなって何もせず終了を待ってしまう
- アイデア同士を組み合わせて新しい案をたくさん出したいのに、既に考えた案についてばかり考えてしまう

また、AIに独創的なアイデアを求めて時間を浪費する場面もありました。

### 製品説明（具体的な製品の説明）

### 特長

#### 1. 特長1

- ブレーンストーミングで行き詰まって手が止まってしまったことを検知し、AIが関連性の低い新しい単語を投下。

#### 2. 特長2

- 出てきた言葉をカードに見たてて全てひっくり返し、神経衰弱のようなゲームを行う。めくった2枚の言葉からアイデアを思いつくことができたら獲得。

#### 3. 特長3

- あくまでもAIは新しい単語を発生させるのみ

### 解決出来ること

- 特長1
  AIによって追加された言葉から新たに言葉を広げることを促し、ユーザーの新しい発想のきっかけを作る。
- 特長2
  出てきた言葉全体を意識させ、様々なアイデアの創出を促すと同時にユーザーの視野が狭くなることを防ぐ。
- 特長3
  アイデアを考える部分はユーザーの独創性にゆだね、AIには考えつかないアイデアが期待できる。
